☁️ Хмарна синхронізація (JSONBin.io)

Безкоштовне хмарне сховище. Дані доступні з будь-якого пристрою.

1 Зареєструйтесь на jsonbin.io (безкоштовно)
2 В акаунті: API Keys → Master Key — скопіюйте ключ
3 Вставте ключ нижче та натисніть "Перший запуск"
4 Збережіть Bin ID — він потрібен на інших пристроях

🔗 Код синхронізації (без реєстрації)

Скопіюйте код і вставте на іншому пристрої — всі дані перенесуться. Не потребує інтернету.

📂 Імпорт з CSV

Завантажте файл CSV з даними клієнтів. Підтримується формат експорту цього додатку або Google Sheets.
